# نور الأمل | تطبيق تقارير الفرصة الثانية

تطبيق جديد مستقل، مبني من الصفر، باللغة العربية (RTL)، لإدارة:

- تقارير حصص **التكوين المهني**.
- تقارير حصص **التأهيل التربوي**.
- **الحضور والغياب**، التأخر والغياب المبرر.
- تقارير **الأنشطة الموازية**.
- لوحة قيادة وإحصائيات وتصفية حسب المركز والتاريخ والحالة.
- تحرير وطباعة التقارير (يمكن الحفظ PDF عبر نافذة طباعة المتصفح).
- تصدير CSV، نسخ احتياطي JSON واستعادته.
- إعداد أسماء المراكز والمجموعات.

## إدارة المراكز والمجموعات — المرحلة الثالثة

- صفحة الإدارة المحمية: `https://nour-alamal-reports.vercel.app/admin` (أو `/admin.html`).
- لا تعرض وظائف الإدارة إلا لحساب موظف **نشط** بدور `admin` في قاعدة البيانات المستقلة `nkrbnwvccnsanetmmuqm`.
- إضافة مراكز ومجموعات مرتبطة بها باستخدام مصادقة Supabase وصفوف RLS. لا تحتاج إلى إرسال كلمة مرور للإدارة أو حفظ مفاتيح ذات امتيازات مرتفعة في المتصفح.
- بعد تسجيل الدخول في `/login`، يظهر رابط لوحة الإدارة للمدير فقط.
- **لم يتم إدخال أي مراكز أو مجموعات تلقائيًا.** أضف الأسماء الصحيحة بنفسك من لوحة الإدارة.
- إنشاء التقارير والحضور على الصفحة الرئيسية ما زال يحفظ محليًا ولا يستخدم حساب المدير بعد؛ لا تضع بيانات مستفيدين حقيقية هناك.

## صفحة الدخول التجريبية للموظفين

- `login.html` و`login.mjs` و`login.css`: تسجيل الدخول والمصادقة عبر مشروع Supabase **الجديد**.
- `supabase-config.mjs`: URL ومفتاح Supabase **publishable** العام، دون أي مفتاح secret.
- `supabase/AUTH_SETUP.md`: دليل دعوة المسؤول الأول وتفعيل حسابه من Supabase.
- رابط الدخول: `https://nour-alamal-reports.vercel.app/login`.

**تحذير:** صفحة تسجيل الدخول تختبر هوية الموظف ودوره فقط؛ التقارير في `index.html` لا تزال محلية وتجريبية وغير مؤمنة بعد. لا تدخل فيها أي بيانات حقيقية.

## التشغيل

افتح `index.html` في المتصفح، أو انشر هذه الملفات بوصفها **Static Site** على Vercel أو GitHub Pages. لا توجد تبعيات JavaScript أو خطوة Build.

## النشر على Vercel

1. أنشئ مشروعاً جديداً باسم `nour-alamal-reports`.
2. اختر Other/Static واجعل مجلد المشروع Root Directory.
3. ارفع `index.html` و`styles.css` و`app.js` و`favicon.svg` و`vercel.json`.
4. انشر المشروع. يمكن ربطه بعد ذلك بمستودع GitHub خاص جديد لتفعيل النشر التلقائي.

## مهم جداً: بيانات تجريبية فقط

واجهة **التقارير** ما زالت نسخة أولية محلية تعمل بـ `localStorage`، رغم وجود صفحة منفصلة لاختبار تسجيل الدخول وصلاحيات الموظفين. لم تُربط التقارير بعد بقاعدة البيانات المركزية، ولا تتوفر نسخ احتياطية من الخادم. البيانات لا تتزامن بين الأجهزة وقد تُفقد عند حذف بيانات المتصفح. لهذا:

**لا تدخل معلومات شخصية أو أسماء حقيقية للمستفيدين، وخصوصاً القاصرين.** استخدم رموزاً تجريبية.

قبل الاستعمال الرسمي: دمج Supabase Auth أو خدمة مصادقة مناسبة، قاعدة بيانات مركزية مع سياسات وصول حسب الدور والمركز (RLS)، تشفير، سجلات تدقيق، نسخ احتياطي وعمليات تصدير مؤمّنة، والتحقق من متطلبات القانون المغربي 09-08 وحماية بيانات القاصرين.
